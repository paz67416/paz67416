# Masashi Awata / 粟田正志

Independent researcher exploring consciousness, qualia, kamae (preparatory stance), and AI through theoretical research, experimental protocol design, and LLM prompt evaluation.

意識・クオリア・構え・AIを研究しています。理論研究と実験的検証に向けたプロトコル設計に加え、LLMへの指示が回答・課題成績・評価者判断に与える影響を検討しています。ブラウザで使える小さな道具やゲームも制作しています。

## Latest research

- **2026-11-18 · Preprint, v1** — [LLMへの構えの指示は何を変えるのか — 偽薬対照によるプロンプト効果の検証と測定上の課題](https://doi.org/10.5281/zenodo.24344070)  
  構えの指示と偽薬対照を比較した未査読の第1報。回答特徴の変化は見られた一方、対照を上回る一貫した課題成績の改善は確認されていません。
- **2026-11-15 · Report, v1** — [LLM構え実験第1報の検証報告書 — 保存データの独立再計算と実行記録の照合](https://doi.org/10.5281/zenodo.24247357)  
  保存データの別実装による再計算と実行記録の照合を報告し、統計処理や保存記録に残る問題を明記しています。研究仮説の確証や全工程の再現完了を示すものではありません。

元の回答データと再計算コードは両資料の公開セットに含まれません。プロンプトによる行動変化と、LLMの意識・主観的経験の成立は区別しています。
